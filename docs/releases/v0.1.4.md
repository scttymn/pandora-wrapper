## What's changed

- Restored reliable Back navigation on album, artist, and other detail pages. The button follows route changes, supports Enter and Space, and has no visible focus box.
- Added ordinary F7, F8, and F9 shortcuts for replay, play/pause, and skip. Hardware media-key actions remain registered separately with the operating system.
- Fixed thumbs-up and thumbs-down shortcuts to target the current track in the bottom player, including when session history is open.
- Prevented shortcut activation while typing, holding modifiers, repeating a key, or using controls that need arrow keys.
- Limited title-bar spacing adjustments to macOS and narrowed the native permissions granted to Pandora pages.
- Added 18 regression tests and updated build, installation, and manual-update instructions.
- Restored downloadable installers for macOS, Windows, and Linux.

## Downloads and updates

- **macOS:** choose the `aarch64.dmg` for Apple Silicon or `x64.dmg` for Intel. Quit Pandora, open the disk image, and drag Pandora into Applications, replacing the previous copy.
- **Windows:** use the `.msi` or setup `.exe` installer.
- **Linux:** choose the `.AppImage`, `.deb`, or `.rpm` for your distribution.

Updates are installed manually; the app does not have an automatic updater. The macOS apps use ad-hoc signing and are not Apple-notarized, so macOS may require approval in Privacy & Security before opening.

## Verification

All 18 shortcut/navigation regression tests pass. Live macOS checks covered F7/F8/F9, arrow feedback, typing and modifier exclusions, key repeat, and Back activation with Enter and Space. Physical hardware media keys and interactive Windows/Linux behavior still need manual verification.
